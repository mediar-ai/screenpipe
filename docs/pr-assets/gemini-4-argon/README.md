# Gemini 4 Argon desktop discovery

Browser preview of the actual desktop React UI (`bun run dev:web`), with synthetic local settings. This is not a native app or production capture.

The before image uses the existing hosted catalog. The after image uses the response generated by this branch's `handleModelListing`, with synthetic configured Vertex/Gateway bindings. The temporary catalog override was removed after capture. The hosted preset editor lists Argon, and selecting and saving it updates the chat selector to `gemini-4-argon`.

The desktop discovers models dynamically; no production desktop source change is required. The hook regression test verifies Argon metadata, output limits, and account locking.
