# Windows transcript scroll evidence

These privacy-safe images come from the synthetic native overlay fixture. The
fixture drives the real Win32 layered window and production wheel/update paths;
the committed evidence is rendered through the same native `Renderer` against a
solid backdrop so no desktop, customer, or credential content is captured.

The sequence shows live follow, a frozen reading snapshot, repeated Show while
paused, rolling-feed eviction plus a same-length partial update, hide/reopen,
and an immediate return to the quiet live edge. This is not full live-app
acceptance and no narrated demo video is claimed.
