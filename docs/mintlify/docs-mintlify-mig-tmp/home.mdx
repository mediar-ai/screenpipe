Screenpipe records the screen and audio sources you enable while it is running. Search recorded work, automate workflows with scheduled tasks, and give connected AI assistants access to that history.

## What Screenpipe does

- **Captures work context** through screen text, audio transcription, app names, and browser URLs, subject to your recording and privacy settings
- **Stores recordings locally** in `~/.screenpipe/` by default. Cloud transcription, AI providers, sync, and connected apps can send selected data elsewhere; check [privacy data flow](/privacy-data-flow).
- **AI-powered search** — find anything you've seen or heard via natural language or API
- **Scheduled tasks** — scheduled AI agents that summarize your day, track time, sync to Obsidian, and more ([browse scheduled tasks](/task-library)) — click **Scheduled tasks** in the sidebar to install
- **MCP server** — give Claude, Cursor, ChatGPT, and other AI tools memory of your screen ([setup](/mcp-server))
- **Connect your apps** — dozens of integrations: Slack, Notion, Google Calendar, Obsidian, Toggl, HubSpot, Salesforce, Zoom, PostHog, Sentry, and more ([connections](/connections)) — configure in **Settings → Connections**

## Popular use cases

| I want to... | How |
|---|---|
| **Find something I saw on screen** | Search in the app, ask your AI, or `curl localhost:3030/search?q=...` |
| **Get a summary of my day** | Run the [Day Recap scheduled task](/task-library) |
| **Auto-track my time** | Install [Toggl Time Tracker](/task-library) or run Time Breakdown |
| **Transcribe meetings** | Automatic — use [meeting intelligence](/meeting-intelligence), search audio, or install a meeting scheduled task |
| **Give Claude memory of my screen** | [Connect via MCP](/mcp-server) — one click in settings |
| **Sync activity to Obsidian** | [Connect Obsidian](/obsidian) and enable the sync scheduled task |
| **Close my loops** | Ask your AI "what was I working on before lunch?" — [learn more](/use-cases) |

<Note>Run the CLI with `npx -y screenpipe@latest <command>` (and the MCP server with `npx -y screenpipe-mcp`). `/health` is public; protected local API requests can require `-H "Authorization: Bearer <your-api-key>"`. See [API authentication](/getting-started#api-authentication).</Note>
